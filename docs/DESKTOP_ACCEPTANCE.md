# 真机验收清单（本轮未执行部分不得计为通过）

使用本轮完整提交的独立副本，记录操作系统、Python、依赖冻结清单、声卡/驱动、模型版本、config.py（不得含密钥）和提交号。使用合成中文材料，禁止上传个人谈话。

1. 安装依赖和模型；无密钥启动，确认界面展示未配置且开始无法进入服务流程。先验证模型加载失败/完成状态与开始按钮，再填入已获授权的有效密钥。
2. 选择麦克风和耳机普通输出：开始→连续三句话→停止→再次开始→运行中关闭。逐项记录是否恢复及线程是否退出。
3. 至少各 5 条短回答、连续讲话、带 data/hotwords.json 热词、句中停顿和噪声输入。记录识别文字、译文与状态是否对应；不要把噪声过滤为正常语音成绩。
4. 同一设备重插导致索引变化、设备消失且旧索引被其他设备占用、指定输出不可用：确认没有静默切换到其他设备；重选后关闭重开仍恢复正确。
5. 主翻译运行/停止与本地监听关闭/开启分别检查；虚拟声卡播放端→会议软件录音端，配合耳机监听。关闭监听应不再本地播音；停止翻译应不继续写入主输出。
6. 无效密钥、断网、合成失败：记录清晰状态及恢复步骤，不保存密码/请求头/原始私有响应。服务方错误是否可恢复需真实服务条件验证。
7. 延迟用单一 session_id、同一配置分组，至少记录样本数、均值、中位数、P95、超时/丢弃及异常样本数。末次语音→断句、识别、首翻译段、首音频、写入排队分别列示。软件 write 不等于扬声器出声。

本轮云端 PortAudio 枚举 0 个设备：真实麦克风、普通扬声器、虚拟声卡、本地监听、噪声/停顿语音质量和端到端真实延迟均未验收。没有验证本项目有效服务凭据和费用预算，未调用收费服务。上述流程由具备设备、模型与本项目授权服务条件的机器执行；不需要新购云资源。
